情報リテラシーⅡ 中間テスト対策 PWA

【パソコンで動作確認】
1. このフォルダのindex.htmlをダブルクリック（通常の問題演習は動作します）。
2. PWAとしてインストールするにはHTTPSで公開する必要があります。

【無料でスマホに入れる】
1. GitHubで新しい公開リポジトリを作る。
2. このフォルダの6ファイル（index.html, app.js, questions.js, sw.js, manifest.webmanifest, icon.svg）をアップロード。
3. Settings > Pages > Deploy from a branch > main / root を選択し保存。
4. 表示された https://...github.io/... のURLをスマホで開く。
5. Android Chromeならメニューから「ホーム画面に追加」または「アプリをインストール」。iPhone Safariなら共有から「ホーム画面に追加」。

【問題の追加】
questions.js のQUESTIONS配列へ [授業回,難易度,問題文,[選択肢A,B,C,D,E],正解番号(0〜4),解説] を追加。
第15・16回の資料が届いたらここへ追記できます。

※学習記録は端末内のブラウザ保存です。ブラウザデータを削除すると消えることがあります。
